# 🧱 sandbox-rconcept

Ce dépôt contient plusieurs projets web développés et testés par **Rconcept**.  
Il sert d'environnement de **développement (sandbox)** pour héberger plusieurs sites statiques HTML/CSS/JS.

---

## 📁 Structure du dépôt

### 🐴 `PoneyClubRiberal/`
Site vitrine du **Poney Club du Riberal**  
- Technologies : HTML5, CSS3, JavaScript  
- Objectif : Présentation du club, des activités, et réservation en ligne (à venir).  
- Statut : En développement

---

### 🌿 `Geden/`
Site vitrine de la marque **Geden**  
- Technologies : HTML5, CSS3, JavaScript  
- Objectif : Présentation de l’entreprise, de ses services et de son univers graphique.  
- Statut : En cours de finalisation
